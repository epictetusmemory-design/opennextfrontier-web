Pathfinder's Unique Advantages
UNIQUE
🎭
Multi-Persona Identity
Switch between Personal, Corporate, Hobby personas — each a different mind with its own model, system prompt, tone, tier, and key overrides. OpenClaw has one identity.
UNIQUE
🏛️
Sovereignty by Architecture
Scout tier blocks cloud LLMs at the Rust command layer — not a config flag. AES-256-GCM vault, PBKDF2, zeroize on drop. Your data's privacy is enforced in code, not promised in a policy.
UNIQUE
🔑
Credentials Manager
Passwords stored in vault at shared.credentials.{id}.password — never in the database. pfcreds format is AES-256-GCM JSON blob. CSV import/export. Retrieve from Telegram with password: intent.
UNIQUE
🦀
Rust + Tauri Native
Not a web app. Not an Electron app. Tauri 2 with Rust backend — memory safe, zero garbage collector, native OS integration, bundled SQLite with no system dependency.
UNIQUE
📚
Trailhead — Self-Aware AI
Pre-installed Eagle persona that knows Pathfinder intimately. Docs auto-indexed at startup, RAG-injected into every query. Ask Pathfinder how to use Pathfinder — it answers from documentation.
UNIQUE
⏰
Cron Scheduler
AI jobs that run while you sleep. Morning briefs, research digests, reminders — all delivered to Telegram. One-shot or recurring. Per-job history. Survives app restart.
